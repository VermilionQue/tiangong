# 山君与可选集成

天工录是一套供家庭成员与智能助手协作管理的模块化工作台。已经使用 OpenClaw、Codex、WorkBuddy 等工具的部署者，可以按各工具的能力配置浏览器或接口访问；当前并未提供这些工具的一键接入插件。访问仍须经过实际部署的登录、账号权限与同源等检查，不应让助手绕过权限直接修改数据库。

天工录的记录、餐单和营养估算不依赖大模型。山君分析通过部署者已安装的 OpenClaw 调用；山君这个名称不会自动生成模型服务或微信账号。

```sh
export TIANGONG_OPENCLAW_BIN=/absolute/path/to/openclaw
export TIANGONG_OPENCLAW_AGENT=main
```

也可让 `openclaw` 位于服务进程的 PATH 中。需要 OpenClaw 支持当前 `gateway call agent` 操作；此候选版未验证所有历史或未来版本。

在菜谱中主动点击分析后，程序整理近期已确认用餐记录、当前餐单、忌口、目标和经授权共享的健康摘要，交给独立分析会话。不发送医疗附件，不将缺少记录当作没有吃饭；同一内容的重复请求会去重。超时显示结果未确认，不会自动盲目重发。

本调用不向微信投递，也不新增每日调度。微信是否能主动发送消息、回复窗口与渠道权限由使用的接入方式决定；天工录不绕过渠道限制。需要微信提醒时，在现有 OpenClaw 渠道中单独配置并验证，避免与已有自动化重复通知。

Apple 提醒事项依赖另行安装的原生辅助程序；本仓库首发不含该程序，默认未连接。Apple 健康导入目录可用 `TIANGONG_HEALTH_IMPORT_DIR` 指定。没有这些外部工具也能使用天工录主体功能。

云端主数据切换、系统 DNS 配置和隧道守护属于现有可选模块，默认不启用；首发推荐先完成单实例本地部署和备份验收。
